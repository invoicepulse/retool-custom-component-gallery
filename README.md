# Retool Custom Component Gallery

A community-driven gallery of custom components built for [Retool](https://retool.com). Browse, use, and contribute your own components.

## What's in this repo

- `index.html` — the gallery UI, browse all accepted components
- `components/` — every accepted custom component, one folder each
- `components/_template/` — copy this to start your own submission

## Browsing components

Open `index.html` in your browser or visit the hosted gallery. Every folder inside `components/` is a self-contained component you can copy directly into your Retool app.

## Submitting a component

1. Fork this repo
2. Copy `components/_template/` and rename it to your component (e.g. `components/pdf-exporter/`)
3. Fill out the `README.md` inside your folder
4. Add your component code (`index.js`)
5. Add a `preview.png` screenshot
6. Open a Pull Request using the PR template

All submissions go through a review process. You will receive an email once your component has been accepted or if changes are needed.
