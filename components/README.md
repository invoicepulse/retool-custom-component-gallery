# Components

Each folder here is an accepted custom component submitted by the Retool community.

## Using a component

1. Open the component folder
2. Read the `README.md` for setup instructions
3. Copy the code from `index.js` into a Retool Custom Component

## Adding your component

Copy `_template/` to a new folder, fill it out, and open a Pull Request.
See [CONTRIBUTING.md](../CONTRIBUTING.md) for full instructions.
